规则 · 槽位 · 物理与强度

随机对战：选择挑战1–10级，双方按相同预算随机组装，强度100起，每级+18。闯关模式：10关，对手强度同样每关+18；胜利拆取一件对手零件，在工坊安装、替换或合成升级。替换件回仓库，装备与技能可卸下。进入下一关时恢复生命。

没有固定职业。1武器槽、2装备槽、3技能槽；每个零件I–III级。同类占一个槽，重复零件可升级。防御罩、无敌、冲刺、瞬移、缩小、巨大化、再生自动周期触发；淬毒、吸血、反伤命中生效。等级越高，武器越长、投射物越多、护盾越宽、技能环层数越多。

物理：质量影响加速度、反弹冲量和转动惯量；伤害由接触点相对速度与有效质量的动能计算。重球难推动，轻球加速快；冲刺增强撞击，巨大化改变半径与质量。实体弧盾和武器共用绘制、碰撞胶囊线段；投射物做扫掠检测。碰撞为亚像素几何近似，并非逐像素透明蒙版或现实精确仿真。

综合强度 = 基础40 + 武器/装备/技能等级分 + 核心储能 + 已定义组合加成。剩余预算转为核心生命。线性的是强度预算，实际胜率仍受相克、碰撞与随机暴击影响。每场45秒，超时比较生命比例；18%暴击、1.75倍伤害；胜负后保留2.2秒终结演出。

备战转动右侧表冠可随机换装；侧键开始/暂停；战斗左滑设置、右滑查看构筑。存档在本浏览器。网页按键模拟不代表原生watchOS系统按键权限，实体触觉取决于设备支持。
