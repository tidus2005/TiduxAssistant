# 安装与首次配对

## Mac

1. 下载与你的 Mac 匹配的 ZIP 或 DMG 和 `SHA256SUMS.txt`；验证 SHA-256。
2. 将 `Tidux助手.app` 拖到“应用程序”。
3. 检查 Release 中的签名状态。当前测试包若未经过 Apple 公证，macOS 可能阻止启动；仅在核实来源后，按 Apple 的官方说明在“系统设置 → 隐私与安全性”查看是否允许单独打开此 App。不要禁用系统安全功能；受管理电脑可能禁止例外。
4. 若系统报告软件损坏、签名异常或恶意软件，停止运行并报告问题，或从源码构建；不要通过删除隔离标记绕过检测。
5. 启动后先使用设备状态和咖啡因；仅为要使用的功能授予权限。

Apple 说明：https://support.apple.com/102445

## 配对 iPhone

先通过你自己的 Xcode 签名安装 iPhone App。两台设备放在附近，开启蓝牙。

1. Mac“连接与设备”点击“开始配对”。
2. iPhone“设备 → 添加 Mac”，在系统窗口选择你的 Mac，并完成系统授权。
3. 输入 Mac 当前显示的配对码，等待“Mac 已连接·蓝牙”。
4. 点击刷新，确认更新时间、电量、温度有真实变化。

若出现加密握手错误，通过 App 的“重新配对此 Mac”完成系统配件关联修复；不要直接关闭蓝牙加密。配对成功后可测试退后台、返回范围后重新连接；iOS 不保证永久后台运行。

## 移动办公

选择时长后开启移动办公，咖啡因自动跟随。先在通风桌面测试合盖，确认实际任务和远控仍可用，再用于出行。无限仅取消逻辑倒计时；温控、供电、系统策略仍有效。

热点需要你配置并先在 macOS 保存；可用 Wi-Fi 会保留。VPN/公司资源仍取决于原有配置与授权。

## Watch

安装同一项目的配套 Watch App，使用系统 WatchConnectivity 与 iPhone 同步。Apple Watch 的第三方表盘组件可添加到支持的系统表盘；无法安装一个取代系统机制的任意第三方表盘。

首次公开版没有公共 TestFlight 链接，不要从不明渠道获取所谓兑换码。
